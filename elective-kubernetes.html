Elective · only if a target role needs it

Kubernetes and portable agent runtimes

Neither target posting mentions Kubernetes; both are AWS-serverless and managed-runtime shops. A full phase on it is time better spent on evals, security and adoption. Keep it as an elective for roles that run persistent or high-scale agent workloads on EKS.

If you take it: learn pods, deployments, services, jobs, config and secrets, resource requests/limits, probes, autoscaling on queue depth rather than CPU, network policies and Helm, then EKS identity. Run the Phase 6 worker contract locally, on ECS and on Kubernetes with externalised state, graceful drain and heartbeats, and write down when Kubernetes is not justified. Learning to say "this does not need Kubernetes" is also a senior skill.
