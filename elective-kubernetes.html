Elective · Only if a target role needs it

Run agents on Kubernetes

The roles this roadmap targets rarely ask for Kubernetes. The teams that hire for them usually run serverless and managed services on AWS. A full phase on Kubernetes would take time away from evals, security, and adoption, so it is an elective. Take it if you target roles that run long-lived or high-volume agent workloads on Amazon Elastic Kubernetes Service (EKS).

If you take it, learn pods, deployments, services, jobs, config maps, secrets, resource requests and limits, probes, network policies, and Helm. Learn to autoscale on queue depth instead of CPU. Then learn how identity works on EKS. Run the Phase 6 worker locally, on ECS, and on Kubernetes, with state stored outside the worker, graceful shutdown, and heartbeats. Write down when a workload does not need Kubernetes. Knowing when to say no to Kubernetes is also a senior skill.
