Tools to know (as of September 2026)

This table dates fastest of anything in the roadmap. Review it at every quarterly checkpoint. Learn the category and its underlying pattern first; the named tools are current examples, not commitments.

Rough priority for the tools named in the job postings and beyond: learn durable execution, sandboxes and gateways properly; give Aspire and LocalStack a targeted pass before applying to AWS- and .NET-heavy platform roles; do not study New Relic separately (OpenTelemetry covers it); pick up everything else when a specific job needs it.

CategoryCurrent examplesDurable pattern to learn
Coding agentsClaude Code (primary), Codex, Cursor, OpenCodeContext files, plan-first work, skills, hooks, permissions, headless use
Agent supervision / multiplexingHerdr (agent-aware, pre-1.0), tmux, Zellij; git worktreesIsolation, visibility of agent state, persistent sessions, gating risky actions
Agent SDKs and orchestrationClaude Agent SDK, LangGraph; situational: Vercel AI SDK (TS), Pydantic AI, Microsoft Agent Framework (.NET)Loops, state machines, supervisors; bare SDK first
Durable executionTemporal; lighter: DBOS, Inngest, Restate; AWS Step FunctionsJournalled steps, replay, long waits, exactly-once side effects
Model gatewaysLiteLLM, Portkey, Bedrock gateway optionsRouting, keys, quotas and cost accounting in one place – and one juicy target
Code-execution sandboxesE2B, Modal, Daytona, Vercel Sandbox, CloudflareIsolation model, egress control, disposable environments
Tool protocolMCP, MCP InspectorNarrow contracts, auth, audit, distribution to teams
ObservabilityOpenTelemetry (GenAI conventions), Langfuse (open source, now part of ClickHouse), New RelicTraces over logs; cost and quality per workflow version; instrument once, export anywhere
EvalsLangfuse datasets/experiments or equivalentVersioned datasets, calibrated judges, CI gates
Cloud and modelsAWS Bedrock, Bedrock AgentCore, Lambda, SQS, Step FunctionsPortable agent contract over managed services
Local devAspire (formerly .NET Aspire), LocalStack (no longer open source), Moto, DockerOne-command environments; recorded model calls; fast, deterministic feedback for agents
