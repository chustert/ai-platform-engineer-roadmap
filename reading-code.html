Read code well and write it rarely

Many roadmaps start with months of learning a programming language by hand. This one does not. One of the two postings says that models write all the code the company ships. Time spent memorising syntax and writing boilerplate trains you for work that agents now do.

You still need to understand code, and you need to understand it better than before. Both postings hold you responsible for what agents produce. One says "review what they give you, own what you merge". The other asks for deep proficiency in C# or Python. An agent can write a thousand lines in a day, and someone has to read those lines critically. The bugs that cause real damage are the ones an agent writes with confidence: a blocking call inside async code, a retry that charges a card twice, a test that asserts nothing, or an authorisation check in the wrong service. A person who cannot read code will merge all of them.

Build code literacy without writing code by hand

Use these five exercises. Do them on code that agents wrote for you.

  • Explain it back. After an agent builds something, describe the control flow aloud or in a short note without looking at the code. Then compare your description with the code. Every gap is a topic to study.
  • Predict, then run. Before you run a change or inject a failure, write down what you expect to happen. When the result surprises you, find out why.
  • Find planted bugs. Ask an agent to add three subtle bugs to a working diff, such as a race condition, a missing authorisation check, and a retry that is not idempotent. Find them without help and track how many you catch.
  • Review by risk. Read every line of code that handles authentication, authorisation, money, deletion, or concurrency. Skim generated UI code and glue code. Write down which files fall in which group for each repository.
  • Ask the agent why. When you see an unfamiliar construct, ask the agent why it chose it, what the alternatives were, and what input would break it.

Interviews still test code

Some Staff-level interviews still test code without AI assistance. In the six weeks before you interview for platform roles, spend about 30 minutes a week reading code and writing small exercises in the target language without help. Treat this as interview preparation. It is not the core skill.
