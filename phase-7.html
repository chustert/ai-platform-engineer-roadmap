Phase 07 · months 6–8

Observability for non-deterministic systems

Outcome

Make every important model, retrieval and tool decision reconstructable so failures can be diagnosed from evidence instead of anecdotes.

Why ordinary logs are not enough

An agent request may contain twenty model calls, fifteen tool calls, several retrieval steps and branches. A flat log stream makes the causal chain almost impossible to follow, so distributed tracing is a first-class AI engineering skill.

OpenTelemetry

Learn traces, spans, context propagation, metrics, logs, collectors, exporters and sampling. Instrument model calls, retrieval, tools, approvals and external APIs with consistent attributes – model, provider, prompt version, workflow version, tokens, cost, tool, tenant, outcome and failure category. Follow the OpenTelemetry GenAI semantic conventions where they fit.

LLM-specific observability

Use Langfuse or an equivalent to inspect traces, prompt versions, token usage, latency and evaluations, and learn how that data reaches a general APM such as New Relic. A trace should answer: what did the agent see, what did it decide, which tool did it call, how long did each step take and what did it cost?

Observe the coding agents too

Coding agents are now among the biggest AI workloads in an engineering organisation. Claude Code, for example, can export usage and cost telemetry over OpenTelemetry. Pipe your own agent usage into the same stack: cost per engineer, per repo and per task type is exactly the cost-governance question a platform team is asked.

Metrics that matter

Task success, p50/p95 latency and cost, token usage, tool error rate, retry rate, timeout/abandonment rate, retrieval quality and human override rate – segmented by workflow and model version so regressions can be localised.

Build: agent operations dashboard

Instrument your product and the PR reviewer end-to-end. Build dashboards for volume, success, latency, cost, model mix, tool failures and top failure categories, with trace links from alerts and correlation IDs carried through queues and workers.

Exit milestone

When an agent misbehaves, you can go from a dashboard anomaly to a specific trace and reconstruct the chain of context, model calls and tool actions that produced the outcome.
