Phase 11 · months 10–12

Build an internal AI platform

Outcome

Move from individual agents to reusable platform capabilities that make safe, observable agent development – and agent-assisted development – easier for every engineering team.

Platform as product

A platform has users, workflows, onboarding friction, reliability expectations and a roadmap. Interview developers and find repeated pain: model integration, tracing, tools, budgets, evaluation, prompt deployment, approvals, identity, context – and, now, getting consistent results from coding agents. Build the smallest paved road that removes real friction.

Two halves of an AI platform

Agent runtime: the gateway, control plane and execution layer for agents your organisation ships (agent definitions, versions, policies, budgets, eval configuration, telemetry). Agentic SDLC enablement: the shared skills, context-file templates, hooks, MCP servers, permission policies and telemetry that make every engineer's coding agents safer and more effective. The Staff platform role is largely the second half; most roadmaps only cover the first.

Reusable primitives

APIs such as create_agent, register_tool, run_eval_suite, require_approval, set_budget and trace_workflow; templates for common patterns rather than one infinitely configurable framework. Defaults should be safe: bounded retries, tracing on, budget required, no privileged tools without policy.

Multi-team concerns

Tenant/team separation, quotas, audit logs, feature flags, staged rollout and version compatibility. Make migrations boring; a platform that breaks every consumer is not leverage.

Build: first Forge platform slice

Package the PR reviewer, context engine and tool servers behind one developer interface: an SDK/CLI, documented local environment, example agent, standard tracing, model gateway and eval hook – plus a shareable agent setup (skills, hooks, MCP config) from Phase 1. Onboard a second agent using only public interfaces to expose accidental coupling.

Exit milestone

Another engineer can create and operate a small agent, and get a well-configured coding-agent setup, from your platform without understanding its internals, while you retain central visibility over spend, reliability and policy.
