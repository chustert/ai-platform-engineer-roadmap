The coding question: read fluently, write rarely

Traditional roadmaps open with months of learning a programming language by hand. That no longer makes sense, and the AI-native product posting states the reason plainly: models write all the code they ship. Practising syntax and hand-writing boilerplate is training for a job that is disappearing.

But "stop writing code" is not the same as "stop knowing code", and this is where the roadmap deliberately disagrees with the strongest version of the argument. Both postings make you accountable for what agents produce: "review what they give you, own what you merge", and "deep proficiency in C# or Python". When agents produce a thousand lines a day, reading them critically becomes more valuable, not less. The failures that hurt in production – a blocking call inside async code, a retry that is not idempotent, a test that asserts nothing, an authorization check on the wrong side of a boundary – are exactly the ones an agent will write confidently and a non-reader will merge.

How to build code literacy without hand-writing code

  • Explain-back: after an agent builds something, explain the control flow aloud or in a short note without looking, then check against the code. Gaps are your study list.
  • Predict, then run: before executing a change or injecting a failure, write down what you expect to happen. Surprises are where real understanding comes from.
  • Seeded-bug review: ask an agent to insert three subtle bugs into a working diff (race, missing auth check, non-idempotent retry) and find them without help. Track your hit rate.
  • Risk-weighted review: read every line of authentication, authorization, money, data deletion and concurrency code; skim generated UI and glue. Write down which is which for each repo.
  • Agent-as-tutor: when you meet an unfamiliar construct, ask the agent why it chose it, what the alternatives were and what would break it.

Interview reality check

Hiring lags practice: some Staff-level loops still test code without AI assistance. In the six weeks before you interview for platform roles, add about 30 minutes a week of unassisted reading and small exercises in the target language (Python or C#). Treat it as interview preparation, not as the core skill.
