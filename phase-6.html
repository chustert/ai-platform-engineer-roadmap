Phase 06 · months 5–7

AWS platform engineering

Outcome

Become strong enough in AWS fundamentals that AI services are just another workload you can deploy securely, economically and repeatably.

The platform base

Go beyond "I can deploy a Lambda". AI platform work often fails on weak cloud fundamentals: overly broad IAM, hidden NAT costs, brittle retries, unbounded Lambda concurrency, no separation between control plane and workload plane. Agents will happily generate infrastructure code for you; they will not tell you it is too permissive unless you know to ask.

Compute and execution

Learn Lambda deeply – concurrency, cold starts and SnapStart, packaging, failure destinations – plus ECS/Fargate for containerised workers and enough EC2 to understand the substrate. Know when serverless is ideal and when a persistent worker pool is cheaper or simpler.

Messaging and workflows

SQS, SNS, EventBridge and Step Functions: visibility timeouts, dead-letter queues, retry semantics, ordering, deduplication and at-least-once delivery. These map directly onto reliable agent execution.

Storage, networking and identity

S3, DynamoDB, RDS/Postgres and ElastiCache used appropriately. VPCs, subnets, security groups, NAT, private endpoints and load balancers. Go deep on IAM, STS, KMS and Secrets Manager: be able to explain exactly which principal can do what and why.

Bedrock and managed agent infrastructure

Learn Bedrock model invocation and the managed agent runtime services AWS offers (such as Bedrock AgentCore), but keep your internal agent contract portable. The goal is to use managed capabilities without coupling every part of the architecture to them.

Build: event-driven agent runner

Run agent jobs from an API through a durable queue. Workers lease work, persist state, emit traces and dead-letter poison jobs. Deploy with Terraform or CDK, isolate environments, use least-privilege roles and produce an infrastructure cost estimate. Review every IAM policy the agent writes by hand.

Exit milestone

You can whiteboard an AWS architecture for an agent platform, explain network and IAM boundaries, predict common failure modes and deploy the stack reproducibly without clicking through the console.
