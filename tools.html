Tools to know

This table lists the tool categories an AI platform engineer uses, current examples in each, and the pattern each category implements. The examples are current as of September 2026.

CategoryCurrent examplesPattern to learn
Coding agentsClaude Code, Codex, Cursor, OpenCode.Context files, planning first, skills, hooks, permissions, and headless runs.
Agent multiplexersHerdr, tmux, Zellij. Git worktrees for isolation.Isolate each agent, show agent state, keep sessions alive, and gate risky actions.
Agent SDKs and frameworksClaude Agent SDK and LangGraph. Vercel AI SDK, Pydantic AI, and Microsoft Agent Framework when they fit.Agent loops, state machines, and supervisors. Start with the model provider's SDK.
Durable executionTemporal. Lighter options are DBOS, Inngest, and Restate. Step Functions on AWS.Record each step, replay after a crash, wait a long time, and run each side effect once.
Model gatewaysLiteLLM, Portkey, Bedrock gateway options.One place for routing, keys, quotas, and cost tracking. That also makes the gateway a target for attackers.
Code sandboxesE2B, Modal, Daytona, Vercel Sandbox, Cloudflare sandboxes.Isolation model, outbound network control, and environments you throw away after use.
Tool protocolMCP and the MCP Inspector.Narrow tool contracts, authentication, audit logs, and distribution to teams.
Tracing and monitoringOpenTelemetry with its generative AI conventions. Langfuse, which ClickHouse acquired in January 2026 and which is still open source. New Relic.Traces instead of logs, cost and quality for each workflow version, and one instrumentation for any backend.
EvalsLangfuse datasets and experiments, or an equivalent.Versioned datasets, calibrated judges, and CI gates.
Cloud and modelsAWS Bedrock, Bedrock AgentCore, Lambda, SQS, Step Functions.Portable agent interfaces on top of managed services.
Local developmentAspire, formerly .NET Aspire. LocalStack, which is no longer open source. Moto. Docker.Environments that start with one command, recorded model calls, and fast, repeatable feedback for agents.
